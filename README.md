# Voice-commands-recognition

Диплом, который состоит также из курсовых работ.

Управление механическим манипулятором голосом с помощью моделей для распознавания голосовых команд и детекции голосовой активности.

## ⚙️ Структура

- `models/` — предобученные модели в ONNX (`vad.onnx`, `command_recognizer.onnx`)
- `src/voice/` — обработка аудио, VAD, распознавание команд
- `src/control/` — преобразование команд в действия и управление манипулятором
- `configs/` — YAML-конфиги: аудиопараметры, карта меток, карта команд
- `scripts/` — отладочные и тестовые скрипты
- `main.py` — разовая обработка голосовой команды с микрофона или файла
- `main_live.py` — непрерывная работа: голос → команда → действие

## 🚀 Быстрый старт

1. Установи зависимости:

```bash
pip install -r requirements.txt
```

2. Запусти основной сценарий:

```bash
python src/main.py
```

3. Запусти потоковый режим:

```bash
python src/main_live.py
```

## 🧠 Архитектура системы

```
Микрофон → [VAD] → [SpeechCommandModel] → [ArmController]
```

- Ресемплирование и извлечение признаков выполняется через `librosa`.
- Распознанные команды сопоставляются с действиями манипулятора через YAML-карту.

## 📁 Конфиги

- `audio_config.yaml` — параметры обработки аудио и признаков
- `voice_commands.yaml` — метки команд и пороги уверенности
- `arm_commands.yaml` — маппинг: команда → позиции серво (канал: импульс)
